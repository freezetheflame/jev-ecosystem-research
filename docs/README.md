## 分类边界

- **应用设计与效果评测**：请求如何组织归应用主题；是否更准、更快归评测主题。
- **安全判别与路由攻击**：MSB、MCPTox、AgentDojo 的分类结果归评测主题；操纵模型路由选择归路由安全。
- **对抗攻击与语义鲁棒性**：JevOut 有固定错误目标和搜索预算；语义鲁棒性同时考察等价不变、关键变化敏感与相同请求噪声。两者互相参考，但不合并实验结果。
- **模型能力与系统收益**：离线判断指标归评测；实际 Agent 的任务成功、上下文准入、缓存和总成本归 Agent 接入。
- **跨主题材料**：只保留一个主归属，在其他主题索引中交叉引用。生态主报告里的榜单属于其历史综述，评测主题引用同一份数据。

## 资料层次

| 层次 | 位置 | 使用方式 |
|---|---|---|
| 调研与结论 | `docs/<topic>/` | 每个主题先读 README，再读专题报告 |
| 来源、样本和结果 | `data/` | 各主题索引列出对应路径；历史快照与运行输出保持原位置 |
| 运行与共享工具 | `scripts/`、`.pi/` | 各主题索引关联脚本；共享客户端不重复复制 |
| 本地源码、权重与应用 | `data/mu/`、`data/JevOut/`、`local-models/`、`local-apps/` | 与本仓库报告区分；保留各自版本、许可证和本地环境要求 |
| 相邻评测项目 | `../jev/` | 部分完整安全评测报告在相邻仓库，本仓库提供链接与总结 |

分类规则、新材料命名和旧路径对照见 [组织约定](organization.md)。
