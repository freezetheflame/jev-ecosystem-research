# 不用本地部署就能调用的强 Jev 类模型

整理自 2026-10-02 的核查。结论先行：**API 可直接调用的里面，真正强的少得可怜**——三个最强的（Imajev-4B 67.4、Plumb-4B 65.8、decider-4b v2 64.1）全都要自己部署权重。

---

## 一、评分陷阱：别直接看总分

**JevBench 总分里 Speed + Cost 占了一半权重**，所以"快且便宜"就能拿高分。

看能力要看 **`sealed_accuracy`（密封集准确率），随机基线 29.3%**。

---

## 二、非官方 API 清单（站点均已实测可达）

| 服务 | 端点 | 总分 | 公开 / **密封** | p50 | \$/千次 |
|---|---|---:|---|---:|---:|
| **Autoloops**（Gemma 4 31B IT） | autoloops.ai | 30.0 | 92.8% / **45.8%** | 0.60s | ~0.136 |
| **djev**（Maisa） | api.djev.dev 免费预览 | 52.2 | 84.0% / 29.9% | 0.24s | 0.026 |
| decision-machine-1 | milliseconds.ai | 39.9 | 67.5% / **25.6%** | **0.17s** | 0.035 |
| SimpleJev Qwen3.8-27B | Featherless demo | 34.6 | 86.6% / 35.7% | 2.03s | 0.104 |
| openjev-sglang | ekzhang demo | 27.7 | 85.3% / 33.1% | 1.36s | 0.131 |
| Instinct | ZooWork 免费评测端点 | 11.4 | 86.6% / 35.1% | 0.52s | 0.325 |
| system-one-open | Modal demo（非生产） | 45.1 | 73.2% / 27.6% | 1.30s | 0.015 |

### 唯一值得认真看的是 Autoloops

密封准确率 **45.8% 是全榜第一**——官方 Jev 只有 36.7%，比它还低 9 个点；智能轴 59.8 也高于 Jev 的 53.1，校准 79.2。

它总分只有 30 是因为**速度慢、成本高被压分，不是因为弱**。

> 如果你要的是"判得准"而不是"总分高"，它是 API 里唯一的选择。代价：专有服务、无公开定价。

### 反过来，这两个别当真

**djev 和 milliseconds.ai 的密封准确率是 29.9% 和 25.6%，而随机瞎猜是 29.3%**——等于分布外毫无能力，后者甚至比瞎猜还差。它们总分高纯粹因为快和便宜。

---

## 三、classifier.dev 陷阱（重要）

总分 **70.82，全场最高**，比官方 Jev 的 63.29 还高 7 分多，成本只要 \$0.0033/千次——是官方的 1/12。

但它 `underlying` 字段白纸黑字写着：

> **"Jev (TypeSafe) behind classifier.dev's zero-shot classification API"**

榜单不给它排名，理由就是 "runs on Jev"。它赢在 fast tier 封装（S 87.6、K 84.3），智能轴 51.6 反而**低于** Jev 的 53.1。

所以：**它不算"非官方模型"，但如果你不在乎血统、只在乎"能调到的强 Jev 能力 + 便宜"，它反而是性价比最高的一条路。**

---

## 四、还有一条路：托管推理上跑开源权重

Fireworks / Chutes / Featherless / Together 这类托管推理上直接跑开源权重——不算本地部署，但用的是非官方模型。

例如 Gemma 4 31B IT 在 Fireworks 上就有 API，Autoloops 本质上就是这么干的（Gemma 4 31B + 决策读出）。

把 Imajev-4B 或 decider-4b 的权重丢上去，你就能同时拿到"最强"和"不用自己管机器"。
